== Nome

naan - calcular um número a partir de um nome

== Sinopse

*naan* [_OPTION_]... _NAME_...

== Descrição

*naan* (name as a number) calcula o hash de cada _NOME_ e imprime um número decimal por argumento.

O número é:

  (digest(NAME) mod DIV) + BIAS

O digest é interpretado como inteiro big-endian.  O hash padrão é SHA-256.  O intervalo padrão é o perfil *w* (`DIV=65536`, `BIAS=0`).

== Opções

*-5, --md5*::
    Usar MD5.

*-1, --sha1*::
    Usar SHA-1.

*--sha224*::
    Usar SHA-224.

*-2, --sha256*::
    Usar SHA-256.

*--sha384*::
    Usar SHA-384.

*-8, --sha512*::
    Usar SHA-512.

*-3, --sha3-256*::
    Usar SHA3-256.

*--sha3-512*::
    Usar SHA3-512.

*--blake2s*::
    Usar BLAKE2s.

*--blake2b*::
    Usar BLAKE2b.

*--ripemd160*::
    Usar RIPEMD-160.

*--crc16*::
    CRC-16/CCITT-FALSE (poly `0x1021`, init `0xFFFF`).

*-c, --crc32*::
    CRC-32/ISO-HDLC.

*-m, --mod* _DIV_::
    DIV.

*-b, --bias* _BIAS_::
    BIAS.

*-p, --profile* _NAME_::
    b, w, dw, wm.

*-h, --help*::
    --help

*--version*::
    --version

== Perfis

*b*::
    sha256 `DIV=256` `BIAS=0`

*w*::
    sha256 `DIV=65536` `BIAS=0`

*dw*::
    sha256 `DIV=4G` `BIAS=0`

*wm*::
    sha1 `DIV=2000` `BIAS=0`

== Exemplos

  $ naan hello
  38948

  $ naan --crc32 hello
  42630
