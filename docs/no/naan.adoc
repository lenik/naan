== Navn

naan - beregn et tall fra et navn

== Synopsis

*naan* [_OPTION_]... _NAME_...

== Beskrivelse

*naan* (name as a number) hasher hvert _NAVN_ og skriver ett desimaltall per argument.

Tallet er:

  (digest(NAME) mod DIV) + BIAS

Digest tolkes som et big-endian-heltall.  Standardhash er SHA-256.  Standardområdet er profil *w* (`DIV=65536`, `BIAS=0`).

== Valg

*-5, --md5*::
    Bruk MD5.

*-1, --sha1*::
    Bruk SHA-1.

*--sha224*::
    Bruk SHA-224.

*-2, --sha256*::
    Bruk SHA-256.

*--sha384*::
    Bruk SHA-384.

*-8, --sha512*::
    Bruk SHA-512.

*-3, --sha3-256*::
    Bruk SHA3-256.

*--sha3-512*::
    Bruk SHA3-512.

*--blake2s*::
    Bruk BLAKE2s.

*--blake2b*::
    Bruk BLAKE2b.

*--ripemd160*::
    Bruk RIPEMD-160.

*--crc16*::
    CRC-16/CCITT-FALSE (poly `0x1021`, init `0xFFFF`).

*-c, --crc32*::
    CRC-32/ISO-HDLC.

*-m, --mod* _DIV_::
    DIV.

*-b, --bias* _BIAS_::
    BIAS.

*-p, --profile* _NAME_::
    b, w, dw, wm.

*-h, --help*::
    --help

*--version*::
    --version

== Profiler

*b*::
    `DIV=256` `BIAS=0`

*w*::
    `DIV=65536` `BIAS=0`

*dw*::
    `DIV=4G` `BIAS=0`

*wm*::
    `DIV=2000` `BIAS=2000`

== Eksempler

  $ naan hello
  38948

  $ naan --crc32 hello
  42630
