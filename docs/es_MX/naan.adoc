== Nombre

naan - calcular un número a partir de un nombre

== Sinopsis

*naan* [_OPTION_]... _NAME_...

== Descripción

*naan* (name as a number) calcula el resumen de cada _NOMBRE_ e imprime un número decimal por argumento.

El número es:

  (digest(NAME) mod DIV) + BIAS

El resumen se interpreta como entero big-endian.  El hash predeterminado es SHA-256.  El rango predeterminado es el perfil *w* (`DIV=65536`, `BIAS=0`).

== Opciones

*-5, --md5*::
    Usar MD5.

*-1, --sha1*::
    Usar SHA-1.

*--sha224*::
    Usar SHA-224.

*-2, --sha256*::
    Usar SHA-256.

*--sha384*::
    Usar SHA-384.

*-8, --sha512*::
    Usar SHA-512.

*-3, --sha3-256*::
    Usar SHA3-256.

*--sha3-512*::
    Usar SHA3-512.

*--blake2s*::
    Usar BLAKE2s.

*--blake2b*::
    Usar BLAKE2b.

*--ripemd160*::
    Usar RIPEMD-160.

*--crc16*::
    CRC-16/CCITT-FALSE (poly `0x1021`, init `0xFFFF`).

*-c, --crc32*::
    CRC-32/ISO-HDLC.

*-m, --mod* _DIV_::
    DIV.

*-b, --bias* _BIAS_::
    BIAS.

*-p, --profile* _NAME_::
    b, w, dw, wm.

*-h, --help*::
    --help

*--version*::
    --version

== Perfiles

*b*::
    `DIV=256` `BIAS=0`

*w*::
    `DIV=65536` `BIAS=0`

*dw*::
    `DIV=4G` `BIAS=0`

*wm*::
    `DIV=2000` `BIAS=2000`

== Ejemplos

  $ naan hello
  38948

  $ naan --crc32 hello
  42630
