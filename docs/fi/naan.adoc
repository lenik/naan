== Nimi

naan - laske luku nimestä

== Yhteenveto

*naan* [_OPTION_]... _NAME_...

== Kuvaus

*naan* (name as a number) tiivistää jokaisen _NIMEN_ ja tulostaa yhden desimaaliluvun argumenttia kohden.

Luku on:

  (digest(NAME) mod DIV) + BIAS

Tiiviste tulkitaan big-endian-kokonaislukuna.  Oletustiiviste on SHA-256.  Oletusalue on profiili *w* (`DIV=65536`, `BIAS=0`).

== Valitsimet

*-5, --md5*::
    Käytä MD5.

*-1, --sha1*::
    Käytä SHA-1.

*--sha224*::
    Käytä SHA-224.

*-2, --sha256*::
    Käytä SHA-256.

*--sha384*::
    Käytä SHA-384.

*-8, --sha512*::
    Käytä SHA-512.

*-3, --sha3-256*::
    Käytä SHA3-256.

*--sha3-512*::
    Käytä SHA3-512.

*--blake2s*::
    Käytä BLAKE2s.

*--blake2b*::
    Käytä BLAKE2b.

*--ripemd160*::
    Käytä RIPEMD-160.

*--crc16*::
    CRC-16/CCITT-FALSE (poly `0x1021`, init `0xFFFF`).

*-c, --crc32*::
    CRC-32/ISO-HDLC.

*-m, --mod* _DIV_::
    DIV.

*-b, --bias* _BIAS_::
    BIAS.

*-p, --profile* _NAME_::
    b, w, dw, wm.

*-h, --help*::
    --help

*--version*::
    --version

== Profiilit

*b*::
    sha256 `DIV=256` `BIAS=0`

*w*::
    sha256 `DIV=65536` `BIAS=0`

*dw*::
    sha256 `DIV=4G` `BIAS=0`

*wm*::
    sha1 `DIV=2000` `BIAS=2000`

== Esimerkit

  $ naan hello
  38948

  $ naan --crc32 hello
  42630
