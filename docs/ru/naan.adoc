== Имя

naan - вычислить число из имени

== Обзор

*naan* [_OPTION_]... _NAME_...

== Описание

*naan* (name as a number) хеширует каждое _ИМЯ_ и печатает одно десятичное число на аргумент.

Число:

  (digest(NAME) mod DIV) + BIAS

Дайджест читается как целое в порядке big-endian.  Хеш по умолчанию — SHA-256.  Диапазон по умолчанию — профиль *w* (`DIV=65536`, `BIAS=0`).

== Параметры

*-5, --md5*::
    Использовать MD5.

*-1, --sha1*::
    Использовать SHA-1.

*--sha224*::
    Использовать SHA-224.

*-2, --sha256*::
    Использовать SHA-256.

*--sha384*::
    Использовать SHA-384.

*-8, --sha512*::
    Использовать SHA-512.

*-3, --sha3-256*::
    Использовать SHA3-256.

*--sha3-512*::
    Использовать SHA3-512.

*--blake2s*::
    Использовать BLAKE2s.

*--blake2b*::
    Использовать BLAKE2b.

*--ripemd160*::
    Использовать RIPEMD-160.

*--crc16*::
    CRC-16/CCITT-FALSE (poly `0x1021`, init `0xFFFF`).

*-c, --crc32*::
    CRC-32/ISO-HDLC.

*-m, --mod* _DIV_::
    DIV.

*-b, --bias* _BIAS_::
    BIAS.

*-p, --profile* _NAME_::
    b, w, dw, wm.

*-h, --help*::
    --help

*--version*::
    --version

== Профили

*b*::
    `DIV=256` `BIAS=0`

*w*::
    `DIV=65536` `BIAS=0`

*dw*::
    `DIV=4G` `BIAS=0`

*wm*::
    `DIV=2000` `BIAS=2000`

== Примеры

  $ naan hello
  38948

  $ naan --crc32 hello
  42630

== Код выхода

*0*::
    0

*1*::
    1
