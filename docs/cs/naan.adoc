== Název

naan - vypočítat číslo ze jména

== Přehled

*naan* [_OPTION_]... _NAME_...

== Popis

*naan* (name as a number) zahashuje každé _JMÉNO_ a vypíše jedno desítkové číslo na argument.

Číslo je:

  (digest(NAME) mod DIV) + BIAS

Digest se čte jako celé číslo big-endian.  Výchozí hash je SHA-256.  Výchozí rozsah je profil *w* (`DIV=65536`, `BIAS=0`).

== Přepínače

*-5, --md5*::
    Použít MD5.

*-1, --sha1*::
    Použít SHA-1.

*--sha224*::
    Použít SHA-224.

*-2, --sha256*::
    Použít SHA-256.

*--sha384*::
    Použít SHA-384.

*-8, --sha512*::
    Použít SHA-512.

*-3, --sha3-256*::
    Použít SHA3-256.

*--sha3-512*::
    Použít SHA3-512.

*--blake2s*::
    Použít BLAKE2s.

*--blake2b*::
    Použít BLAKE2b.

*--ripemd160*::
    Použít RIPEMD-160.

*--crc16*::
    CRC-16/CCITT-FALSE (poly `0x1021`, init `0xFFFF`).

*-c, --crc32*::
    CRC-32/ISO-HDLC.

*-m, --mod* _DIV_::
    DIV.

*-b, --bias* _BIAS_::
    BIAS.

*-p, --profile* _NAME_::
    b, w, dw, wm.

*-h, --help*::
    --help

*--version*::
    --version

== Profily

*b*::
    sha256 `DIV=256` `BIAS=0`

*w*::
    sha256 `DIV=65536` `BIAS=0`

*dw*::
    sha256 `DIV=4G` `BIAS=0`

*wm*::
    sha1 `DIV=2000` `BIAS=0`

== Příklady

  $ naan hello
  38948

  $ naan --crc32 hello
  42630
