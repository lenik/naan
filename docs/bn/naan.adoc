== নাম

naan - নাম থেকে সংখ্যা গণনা

== সারাংশ

*naan* [_OPTION_]... _NAME_...

== বিবরণ

*naan* (name as a number) প্রতিটি _নাম_ হ্যাশ করে এবং প্রতি আর্গুমেন্টে একটি দশমিক সংখ্যা ছাপায়।

সংখ্যা:

  (digest(NAME) mod DIV) + BIAS

ডাইজেস্টকে বিগ-এন্ডিয়ান পূর্ণসংখ্যা ধরা হয়। ডিফল্ট হ্যাশ SHA-256। ডিফল্ট সীমা প্রোফাইল *w* (`DIV=65536`, `BIAS=0`)।

== বিকল্প

*-5, --md5*::
    MD5 ব্যবহার করুন।

*-1, --sha1*::
    SHA-1 ব্যবহার করুন।

*--sha224*::
    SHA-224 ব্যবহার করুন।

*-2, --sha256*::
    SHA-256 ব্যবহার করুন।

*--sha384*::
    SHA-384 ব্যবহার করুন।

*-8, --sha512*::
    SHA-512 ব্যবহার করুন।

*-3, --sha3-256*::
    SHA3-256 ব্যবহার করুন।

*--sha3-512*::
    SHA3-512 ব্যবহার করুন।

*--blake2s*::
    BLAKE2s ব্যবহার করুন।

*--blake2b*::
    BLAKE2b ব্যবহার করুন।

*--ripemd160*::
    RIPEMD-160 ব্যবহার করুন।

*--crc16*::
    CRC-16/CCITT-FALSE (poly `0x1021`, init `0xFFFF`).

*-c, --crc32*::
    CRC-32/ISO-HDLC.

*-m, --mod* _DIV_::
    DIV.

*-b, --bias* _BIAS_::
    BIAS.

*-p, --profile* _NAME_::
    b, w, dw, wm.

*-h, --help*::
    --help

*--version*::
    --version

== প্রোফাইল

*b*::
    sha256 `DIV=256` `BIAS=0`

*w*::
    sha256 `DIV=65536` `BIAS=0`

*dw*::
    sha256 `DIV=4G` `BIAS=0`

*wm*::
    sha1 `DIV=2000` `BIAS=0`

== উদাহরণ

  $ naan hello
  38948

  $ naan --crc32 hello
  42630
