== Nome

naan - calcolare un numero da un nome

== Sintassi

*naan* [_OPTION_]... _NAME_...

== Descrizione

*naan* (name as a number) calcola l'hash di ogni _NOME_ e stampa un numero decimale per argomento.

Il numero è:

  (digest(NAME) mod DIV) + BIAS

Il digest è interpretato come intero big-endian.  L'hash predefinito è SHA-256.  L'intervallo predefinito è il profilo *w* (`DIV=65536`, `BIAS=0`).

== Opzioni

*-5, --md5*::
    Usa MD5.

*-1, --sha1*::
    Usa SHA-1.

*--sha224*::
    Usa SHA-224.

*-2, --sha256*::
    Usa SHA-256.

*--sha384*::
    Usa SHA-384.

*-8, --sha512*::
    Usa SHA-512.

*-3, --sha3-256*::
    Usa SHA3-256.

*--sha3-512*::
    Usa SHA3-512.

*--blake2s*::
    Usa BLAKE2s.

*--blake2b*::
    Usa BLAKE2b.

*--ripemd160*::
    Usa RIPEMD-160.

*--crc16*::
    CRC-16/CCITT-FALSE (poly `0x1021`, init `0xFFFF`).

*-c, --crc32*::
    CRC-32/ISO-HDLC.

*-m, --mod* _DIV_::
    DIV.

*-b, --bias* _BIAS_::
    BIAS.

*-p, --profile* _NAME_::
    b, w, dw, wm.

*-h, --help*::
    --help

*--version*::
    --version

== Profili

*b*::
    sha256 `DIV=256` `BIAS=0`

*w*::
    sha256 `DIV=65536` `BIAS=0`

*dw*::
    sha256 `DIV=4G` `BIAS=0`

*wm*::
    sha1 `DIV=2000` `BIAS=0`

== Esempi

  $ naan hello
  38948

  $ naan --crc32 hello
  42630
