== Naam

naan - een getal uit een naam berekenen

== Overzicht

*naan* [_OPTION_]... _NAME_...

== Beschrijving

*naan* (name as a number) hasht elke _NAAM_ en drukt één decimaal getal per argument af.

Het getal is:

  (digest(NAME) mod DIV) + BIAS

De digest wordt als big-endian geheel getal gelezen.  De standaardhash is SHA-256.  Het standaardbereik is profiel *w* (`DIV=65536`, `BIAS=0`).

== Opties

*-5, --md5*::
    MD5 gebruiken.

*-1, --sha1*::
    SHA-1 gebruiken.

*--sha224*::
    SHA-224 gebruiken.

*-2, --sha256*::
    SHA-256 gebruiken.

*--sha384*::
    SHA-384 gebruiken.

*-8, --sha512*::
    SHA-512 gebruiken.

*-3, --sha3-256*::
    SHA3-256 gebruiken.

*--sha3-512*::
    SHA3-512 gebruiken.

*--blake2s*::
    BLAKE2s gebruiken.

*--blake2b*::
    BLAKE2b gebruiken.

*--ripemd160*::
    RIPEMD-160 gebruiken.

*--crc16*::
    CRC-16/CCITT-FALSE (poly `0x1021`, init `0xFFFF`).

*-c, --crc32*::
    CRC-32/ISO-HDLC.

*-m, --mod* _DIV_::
    DIV.

*-b, --bias* _BIAS_::
    BIAS.

*-p, --profile* _NAME_::
    b, w, dw, wm.

*-h, --help*::
    --help

*--version*::
    --version

== Profielen

*b*::
    sha256 `DIV=256` `BIAS=0`

*w*::
    sha256 `DIV=65536` `BIAS=0`

*dw*::
    sha256 `DIV=4G` `BIAS=0`

*wm*::
    sha1 `DIV=2000` `BIAS=2000`

== Voorbeelden

  38948

  $ naan --crc32 hello
