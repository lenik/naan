== Атауы

naan - атаудан сан есептеу

== Шолу

*naan* [_OPTION_]... _NAME_...

== Сипаттама

*naan* (name as a number) әр _АТАУДЫ_ хештейді және әр аргументке бір ондық сан шығарады.

Сан:

  (digest(NAME) mod DIV) + BIAS

Дайджест big-endian бүтін сан ретінде оқылады.  Әдепкі хеш — SHA-256.  Әдепкі ауқым — *w* профилі (`DIV=65536`, `BIAS=0`).

== Опциялар

*-5, --md5*::
    MD5 қолдану.

*-1, --sha1*::
    SHA-1 қолдану.

*--sha224*::
    SHA-224 қолдану.

*-2, --sha256*::
    SHA-256 қолдану.

*--sha384*::
    SHA-384 қолдану.

*-8, --sha512*::
    SHA-512 қолдану.

*-3, --sha3-256*::
    SHA3-256 қолдану.

*--sha3-512*::
    SHA3-512 қолдану.

*--blake2s*::
    BLAKE2s қолдану.

*--blake2b*::
    BLAKE2b қолдану.

*--ripemd160*::
    RIPEMD-160 қолдану.

*--crc16*::
    CRC-16/CCITT-FALSE (poly `0x1021`, init `0xFFFF`).

*-c, --crc32*::
    CRC-32/ISO-HDLC.

*-m, --mod* _DIV_::
    DIV.

*-b, --bias* _BIAS_::
    BIAS.

*-p, --profile* _NAME_::
    b, w, dw, wm.

*-h, --help*::
    --help

*--version*::
    --version

== Профильдер

*b*::
    sha256 `DIV=256` `BIAS=0`

*w*::
    sha256 `DIV=65536` `BIAS=0`

*dw*::
    sha256 `DIV=4G` `BIAS=0`

*wm*::
    sha1 `DIV=2000` `BIAS=0`

== Мысалдар

  $ naan hello
  38948

  $ naan --crc32 hello
