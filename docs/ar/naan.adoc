== الاسم

naan - حساب رقم من اسم

== الملخص

*naan* [_OPTION_]... _NAME_...

== الوصف

*naan* (name as a number) يجزّئ كل _اسم_ ويطبع رقمًا عشريًا لكل وسيط.

الرقم هو:

  (digest(NAME) mod DIV) + BIAS

تُفسَّر الخلاصة كعدد صحيح بترتيب البايتات الكبير. التجزئة الافتراضية هي SHA-256. النطاق الافتراضي هو الملف *w* (`DIV=65536`، `BIAS=0`).

== الخيارات

*-5, --md5*::
    استخدام MD5.

*-1, --sha1*::
    استخدام SHA-1.

*--sha224*::
    استخدام SHA-224.

*-2, --sha256*::
    استخدام SHA-256.

*--sha384*::
    استخدام SHA-384.

*-8, --sha512*::
    استخدام SHA-512.

*-3, --sha3-256*::
    استخدام SHA3-256.

*--sha3-512*::
    استخدام SHA3-512.

*--blake2s*::
    استخدام BLAKE2s.

*--blake2b*::
    استخدام BLAKE2b.

*--ripemd160*::
    استخدام RIPEMD-160.

*--crc16*::
    CRC-16/CCITT-FALSE (poly `0x1021`, init `0xFFFF`).

*-c, --crc32*::
    CRC-32/ISO-HDLC.

*-m, --mod* _DIV_::
    DIV.

*-b, --bias* _BIAS_::
    BIAS.

*-p, --profile* _NAME_::
    b, w, dw, wm.

*-h, --help*::
    --help

*--version*::
    --version

== الملفات

*b*::
    sha256 `DIV=256` `BIAS=0`

*w*::
    sha256 `DIV=65536` `BIAS=0`

*dw*::
    sha256 `DIV=4G` `BIAS=0`

*wm*::
    sha1 `DIV=2000` `BIAS=2000`

== أمثلة

  $ naan hello
  38948

  $ naan --crc32 hello
  42630
