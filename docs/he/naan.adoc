== שם

naan - חישוב מספר משם

== תקציר

*naan* [_OPTION_]... _NAME_...

== תיאור

*naan* (name as a number) מגובב כל _שם_ ומדפיס מספר עשרוני לכל ארגומנט.

המספר:

  (digest(NAME) mod DIV) + BIAS

התמצית נקראת כמספר שלם big-endian. גיבוב ברירת המחדל הוא SHA-256. טווח ברירת המחדל הוא פרופיל *w* (`DIV=65536`, `BIAS=0`).

== אפשרויות

*-5, --md5*::
    השתמש ב-MD5.

*-1, --sha1*::
    השתמש ב-SHA-1.

*--sha224*::
    השתמש ב-SHA-224.

*-2, --sha256*::
    השתמש ב-SHA-256.

*--sha384*::
    השתמש ב-SHA-384.

*-8, --sha512*::
    השתמש ב-SHA-512.

*-3, --sha3-256*::
    השתמש ב-SHA3-256.

*--sha3-512*::
    השתמש ב-SHA3-512.

*--blake2s*::
    השתמש ב-BLAKE2s.

*--blake2b*::
    השתמש ב-BLAKE2b.

*--ripemd160*::
    השתמש ב-RIPEMD-160.

*--crc16*::
    CRC-16/CCITT-FALSE (poly `0x1021`, init `0xFFFF`).

*-c, --crc32*::
    CRC-32/ISO-HDLC.

*-m, --mod* _DIV_::
    DIV.

*-b, --bias* _BIAS_::
    BIAS.

*-p, --profile* _NAME_::
    b, w, dw, wm.

*-h, --help*::
    --help

*--version*::
    --version

== פרופילים

*b*::
    `DIV=256` `BIAS=0`

*w*::
    `DIV=65536` `BIAS=0`

*dw*::
    `DIV=4G` `BIAS=0`

*wm*::
    `DIV=2000` `BIAS=2000`

== דוגמאות

  $ naan hello
  38948

  $ naan --crc32 hello
  42630
