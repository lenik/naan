== Navn

naan - beregn et tal fra et navn

== Synopsis

*naan* [_OPTION_]... _NAME_...

== Beskrivelse

*naan* (name as a number) hasher hvert _NAVN_ og udskriver ét decimaltal pr. argument.

Tallet er:

  (digest(NAME) mod DIV) + BIAS

Digest fortolkes som et big-endian-heltal.  Standardhash er SHA-256.  Standardområdet er profil *w* (`DIV=65536`, `BIAS=0`).

== Tilvalg

*-5, --md5*::
    Brug MD5.

*-1, --sha1*::
    Brug SHA-1.

*--sha224*::
    Brug SHA-224.

*-2, --sha256*::
    Brug SHA-256.

*--sha384*::
    Brug SHA-384.

*-8, --sha512*::
    Brug SHA-512.

*-3, --sha3-256*::
    Brug SHA3-256.

*--sha3-512*::
    Brug SHA3-512.

*--blake2s*::
    Brug BLAKE2s.

*--blake2b*::
    Brug BLAKE2b.

*--ripemd160*::
    Brug RIPEMD-160.

*--crc16*::
    CRC-16/CCITT-FALSE (poly `0x1021`, init `0xFFFF`).

*-c, --crc32*::
    CRC-32/ISO-HDLC.

*-m, --mod* _DIV_::
    DIV.

*-b, --bias* _BIAS_::
    BIAS.

*-p, --profile* _NAME_::
    b, w, dw, wm.

*-h, --help*::
    --help

*--version*::
    --version

== Profiler

*b*::
    sha256 `DIV=256` `BIAS=0`

*w*::
    sha256 `DIV=65536` `BIAS=0`

*dw*::
    sha256 `DIV=4G` `BIAS=0`

*wm*::
    sha1 `DIV=2000` `BIAS=0`

== Eksempler

  $ naan hello
  38948

  $ naan --crc32 hello
  42630
